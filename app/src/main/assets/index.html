Setup steps
1. Turn on Accessibility for AutoSend in Android settings.
2. Allow Alarms & reminders (exact alarms).
3. Keep WhatsApp installed and log in.
4. Add the chat name and message, then tap Save schedule.
5. Tap Send a test message to verify.
